# Будульники — скачать

Будильник, который сам читает расписание БГУИР и будит к первой паре.

## 📥 Последняя версия

**[Скачать APK →](https://github.com/Gudi00/budulniki-releases/releases/latest)**

1. Открой ссылку с телефона и скачай файл `budulniki-…apk`.
2. Разреши установку из браузера, если Android спросит.
3. Дальше обновления приходят сами: приложение покажет «Вышла версия … · Обновить» — настройки, друзья и будильники сохранятся.

Здесь только готовые сборки для Android (7.0+). Приложение неофициальное и не связано с университетом.
